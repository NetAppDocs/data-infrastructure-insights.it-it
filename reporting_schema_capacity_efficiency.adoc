| lossMB | Int64 | SÌ | Capacità persa a causa dell'utilizzo della tecnologia. 0 quando la tecnologia non è specificata (NULL). 


| potentialGainMB | Int64 | SÌ | Potenziale capacità di guadagno derivante dall'utilizzo completo della tecnologia. 0 quando la tecnologia non è specificata (NULL).
