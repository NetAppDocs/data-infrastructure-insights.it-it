= Interrogazione di asset e metriche
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Utilizza le query per cercare e analizzare le risorse della tua infrastruttura e le metriche a un livello granulare. Interroga le risorse di inventario fisiche e virtuali, i dati di integrazione da Kubernetes e ONTAP e le metriche sulle performance per monitorare il tuo ambiente, risolvere problemi e creare viste mirate in base ai tuoi criteri specifici.

Si noti che le regole di annotazione, che assegnano automaticamente annotazioni alle risorse, richiedono una query che è stata condivisa con tutti. Vedere di seguito per ulteriori informazioni sulla condivisione delle query.

È possibile interrogare le risorse di inventario fisiche o virtuali (e le relative metriche) sul tenant oppure le metriche fornite con l'integrazione, ad esempio Kubernetes o ONTAP Advanced Data.



[[inventory-assets]]
== Attività di inventario

Tutti i tipi di asset di inventario (chiamati anche infrastruttura) (storage, switch, VM, Application, ecc.) possono essere utilizzati in query, widget della dashboard e pagine di destinazione degli asset personalizzate. I campi e i contatori disponibili per filtri, espressioni e visualizzazione varieranno tra i tipi di asset.



[[integration-metrics]]
== Metriche di integrazione

Oltre a eseguire query sulle risorse di inventario e sulle relative metriche di prestazioni, è possibile eseguire query anche sulle metriche dei *dati di integrazione*, come quelle generate da Kubernetes o Docker, o fornite con ONTAP Advanced Metrics.

[[sharing-queries]]
== Condivisione delle query

Controlla l'accesso alle tue query scegliendo chi può visualizzarle e modificarle. Per impostazione predefinita, le nuove query sono private e visibili solo a te e puoi scegliere di condividerle con utenti specifici o con l'intera organizzazione con livelli di autorizzazione flessibili (Sola lettura o Modifica).

Puoi scegliere di condividere la query con Everyone o con utenti selezionati, con autorizzazioni di modifica o di sola lettura.


NOTE: Gli utenti con autorizzazione Account Owner possono visualizzare tutte le query, indipendentemente dall'impostazione della privacy.
